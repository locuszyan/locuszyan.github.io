# Keeping the portfolio current

The website has a permanent **Selected Work** area. To add a project later, add one card to `index.html` immediately after the comment `Add new portfolio cards here`.

1. Open `index.html` in GitHub and select **Edit**.
2. Copy one complete `<article class="work-card">` block from the Selected Work section.
3. Paste it next to the existing cards and update the small category label, project title, short factual description, and public project link.
4. If you want a different visual treatment, reuse a class already in `styles.css` (`work-visual-ad`, `work-visual-film`, or `work-visual-character`) or ask me to add a new one.
5. Commit the change to `main`; GitHub Pages publishes the update automatically after its build finishes.

For a new service, repeat an `<article class="service-card">` block from the Services section. Keep service claims and case-study facts accurate, and get client permission before posting confidential material.
